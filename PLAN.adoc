=== Architecture

....
AsciidoctorEpub::Converter
  ├── EpubBuilder     (structure EPUB : OPF, NCX, NAV, metadonnees)
  ├── XhtmlBuilder    (chapitres XHTML5 valides, page de couverture, page de titre)
  └── EpubWriter      (assemblage ZIP avec Compress::Zip, images embarquees)
....
