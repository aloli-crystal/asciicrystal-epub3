= Installation

== En tant que Bibliotheque

Ajouter dans votre `shard.yml` :

[source,yaml]
----
dependencies:
  asciicrystal-epub3:
    github: aloli-crystal/asciicrystal-epub3
    version: "~> 2.3"
----

Puis executer `shards install`.

== Binaire CLI

[source,bash]
----
git clone https://github.com/aloli-crystal/asciicrystal-epub3.git
cd asciicrystal-epub3
shards build --release
ln -s "$PWD/bin/asciicrystal-epub3" ~/bin/
----
